About Me

I'm a Python and Generative AI Developer currently working as a Generative AI Intern at DataBinaries, where I build real-world applications on top of Large Language Models. My work sits at the intersection of Python development, Generative AI, Prompt Engineering, Retrieval-Augmented Generation (RAG), and API-driven automation.

I completed an intensive Generative AI specialization, during which I designed and shipped several end-to-end AI projects — from a PDF-to-Chat assistant powered by RAG, to a YouTube video summarizer, an AI code assistant, and a voice assistant that combines speech-to-text, LLMs, and text-to-speech. Along the way I've worked hands-on with LangChain, vector databases, semantic search, and REST API integration.
